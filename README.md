> Electrifying project templating/scaffolding engine.

`Zappy` is a project templating/scaffolding engine written in Rust to generate projects from a multitude of pre-defined templates. It also allows the user to create their own templates or generate ones from an existing project.

> **Note:** This project is a re-implementation of the [zappy](https://gitlab.com/byarocks/zappy) luarock and takes heavy inspiration from the [spawn_point](https://github.com/normano/spawnpoint/tree/main) crate.

To find out more read [Zappy Book](TBA).

## Why?

> Have you ever been discouraged from starting a new project because of the hassle of setting it up?

> Do you find yourself starting new projects in different languages/ecosystems and it's starting to get hard to track of all the tooling to set them up?

> Or do you find that projects generated by conventional tooling are lacking in multiple regards and still need a lot of stup and broilerplate to get them to a suitable state?

If you've answered "yes" to any of these questions then `Zappy` is here for the rescue. It aims to help you generate new projects from a multitude of pre-defined opinionated templates or create your own, so that you'l never need to spend hours writing and copying config files and boilerplate code while setting up new pojects.

## Features

- **Template generation:** generate tempalte projects from custom or bundled project templates
- **Template variables:** placeholders in tempalte files replaced with provided values.
- **Variable transformations:** zappy transforms provided variable values to different castings (camel case, kebab case, ...)
- **Conditional includes**: include/exclude specific files/directories based on provided variable values.
- **Pre/Post generation hooks:** run custom commands before and after project generation.
- **Template validation:** integrated build/test steps in template manifest to ensure zappy generates a working project.

## Usage

```bash
Usage: zappy [OPTIONS] <COMMAND>

Commands:
  list      List available templates
  info      Display detailed info about a template
  new       Generate a new project from a template
  validate  Validate that a template generates a working project
  init      Initialize an empty template skeleton
  create    Create a template from an existing project, or create an empty template skeleton
  help      Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose...  Output verbosity. Use `-v`, `-vv`, `-vvv` for increasingly detailed output
  -c, --clear       Clear templates cache before executing a command
  -h, --help        Print help
  -V, --version     Print version
```

## Templates

Each template contains 2 things:
1. `zappy.toml` template manifest file,
2. source root directory containing template files.

### Built-in templates

| Id | Name | Language | Description |
| --------------- | --------------- | --------------- | --------------- |
| `cpp-cmake-app` | C++ Cmake app | `cpp` | C++ app managed by CMake build system |
| `cpp-cmake-lib` | C++ Cmake library | `cpp` | C++ static library managed by CMake build system |
| `lua-cli` | Lua CLI app | `lua` | Luarock-bundled Lua-based CLI application using argparse |
| `nvim-plugin` | Neovim plugin | `lua` | Neovim editor plugin for its lazy.nvim package manager |
| `rust-cli` | Rust CLI app | `rust` | Rust-based CLI application using clap |

## Development

### Prequisites

- Rust stable toolchain with `rustfmt` and `clippy` (`rust-toolchain.toml`)
- Rust `1.85.0` or newer for workspace builds
- [`just`](https://crates.io/crates/just)

For a first time setup, run:
```bash
cargo install just
just init
```

This installs just and its `init` bootstrap recipe installs all extra tooling used by this repository, including coverage, lint/audit tools, README indexing, pre-commit hooks and more.

### Getting started

Build zappy:
```bash
just build
```

Run zappy:
```bash
just run -- <pass in args>

```

or install it locally:
```bash
just install
```

Run tests:
```bash
just test
```

Before committing work:
```bash
just pre-commit

```

To see all available recipes:
```bash
just list

# or

just help
```

### Common commands:

```bash
just list
just fmt
just check
just test
just test-cov
just test-templates
just pre-commit
```

### Coverage and benchmarks

Coverage and CI-oriented quality gates:
```bash
just test-cov
just test-cov-ci
just ci
```
